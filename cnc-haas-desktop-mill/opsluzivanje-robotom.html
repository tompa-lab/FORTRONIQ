HAAS DESKTOP MILL · KOBOT UR3e · OPSLUŽIVANJE STROJA

Opsluživanje stroja robotom

Kobot UR3e opslužuje Desktop Mill — stanica, signali i ciklus

Kobot UR3e stoji pred podignutim zaštitnim vratima stroja: uzima pripremak s palete, stavlja ga u niski pneumatski škripac, zatvara vrata, daje stroju signal CYCLE START, čeka signal kraja programa, vadi obradak i odlaže ga na izlaznu paletu. Četiri niza: stanica i signali, ručno ispitivanje ulaza i izlaza, izvođenje ciklusa i oporavak nakon pogreške. Uputa je ispod privjeska, pomoć se otvara klikom na „Pomoć”.

Robot i njegov program vode stanicu (robot je „gospodar”, CNC izvršava jedan program) · privjesak je naš pojednostavljeni prikaz nalik PolyScopeu · pneumatski škripac i automatska vrata su izmišljeni i tako označeni — stvarni Desktop Mill ima ručni škripac i zaštitna vrata koja se ručno podižu.

Moći ću:
  • opisati raspored robotske stanice i razmjenu signala robot ↔ CNC (DO/DI)
  • ručno ispitati signale: vrata, škripac, CYCLE START i kraj programa
  • pratiti program robota (MoveJ, MoveL, Set, Wait, petlja) kroz cijeli ciklus utovara, obrade i istovara
  • prepoznati zastoj zbog otvorenih vrata (door hold) i nastaviti rad
  • zaustaviti stanicu nužnim zaustavljanjem i nastaviti program nakon Reset

    CNC program O01010 (ROBOT DZEP)

    Nizovi u ovom poglavlju

    1. Stanica i signali — raspored: stroj, robot na postolju, palete, pneumatski škripac, automatska vrata; tablica ulaza i izlaza između robota i stroja.
    2. Ručno ispitivanje signala — kartica I/O: otvaranje i zatvaranje vrata (DO3, DI1), stezanje škripca (DO1, DI2), pokretanje CNC programa (DO2) i signal kraja (DI0) — bez pripremka, „u prazno”.
    3. Izvođenje ciklusa — program robota: dva pripremka s ulazne palete, obrada na stroju, odlaganje na izlaznu paletu; praćenje naredbi u stablu programa.
    4. Pogreška i oporavak — ručno otvaranje vrata za vrijeme obrade (door hold), nastavak s CYCLE START; nužno zaustavljanje robota i nastavak programa s Play.

    Razmjena signala robot ↔ stroj (naša dodjela)

    SignalSmjerZnačenje

    DI3hvataljka → robotOn = predmet u hvataljci

    Što je pretpostavka ili pojednostavljenje

    • Stvarni Desktop Mill nema pneumatski škripac, automatska vrata ni priključke za daljinski CYCLE START i signal kraja programa — sve je to naš dodatak za vježbu opsluživanja; u sljedećem koraku povezat će se s elektropneumatikom i PLC-om (Siemens S7-1500/1200).
    • Robot je gospodar stanice: njegov program daje stroju CYCLE START i čeka kraj. Stroj izvodi jedan program (O01010) bez privjeska; prije izlaska robota osi stroja odlaze u položaj za utovar.
    • Privjesak robota je pojednostavljen: program je zadan i prikazuje se kao stablo (nije uređivanje točaka — to je u području Kobot UR3e); brzina, Play/Pause/Stop, I/O i Log rade kao na privjesku.
    • Robot se ne provjerava na sudar s kabinom ni sa strojem; hvataljka, postolje robota, palete i mjere stanice su naš postav. Kinematika UR3e je iz DH parametara (isti model kao u području Kobot UR3e).
